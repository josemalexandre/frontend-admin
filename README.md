# frontend-admin

Template de interface administrativa desenvolvido com **HTML5**, **CSS3** e **JavaScript**, projetado para servir como base para aplicações web.

## Objetivo

Disponibilizar uma interface moderna, responsiva e reutilizável para integração com diferentes back-ends, como Flask, Django, FastAPI ou outras tecnologias.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Bootstrap Icons
